# 小智 AI 行为规则说明

## 什么是 AI 行为规则？

AI 行为规则（System Prompt / 系统提示词）决定了小智在回答问题时如何思考、如何组织语言、以及能做什么不能做什么。你可以通过编辑规则文件来**定制小智的行为风格**。

## 规则文件位置

```
config/ai_rules.txt
```

## 如何修改规则

### 方法一：托盘菜单（推荐）

1. 运行程序后，在**系统托盘**（右下角水蓝蓝图标）右键
2. 点击 **「📝 编辑AI规则」**
3. 系统会自动用记事本打开 `ai_rules.txt`
4. 修改后**保存**文件，**重启程序**生效

### 方法二：手动编辑

直接打开项目目录下的 `config/ai_rules.txt`，用任何文本编辑器修改即可。

## 规则格式说明

规则文件是纯文本格式，每条规则一行，建议用数字编号：

```
1. 第一条规则，描述小智应该做什么
2. 第二条规则，描述小智不应该做什么
...
```

**注意事项：**
- 规则越具体越好，避免模糊描述
- 规则文件保存为 UTF-8 编码（记事本默认就是）
- 修改后必须**重启程序**才能生效
- 修改出错时可以删除 `config/ai_rules.txt` 文件，程序会自动重建默认规则

## 规则示例

```
1. 查询精灵时，名字必须完全匹配才能查到，不能模糊匹配
2. 查询蛋时，进化链上任意形态都回答基础（幼年）形态的蛋
3. 找不到信息时直接说"不知道"，不要瞎编
4. 回复要简洁，不要啰嗦
```

## 内置规则（不可修改）

除了自定义规则外，小智还内置了以下**不可修改**的基础规则：

- 仅基于本地知识库回答问题，不联网搜索
- 找不到相关信息时回复固定提示语
- 不影响内部数据查询逻辑（如精灵数据、技能数据等）
- 回复中用 `[IMG:精灵名]` 标记图片位置（前端自动渲染）

## 工作原理

```
程序启动
  │
  ├── 读取 config/ai_rules.txt（自定义规则）
  │
  └── 合并内置规则 → 构建完整 System Prompt
       │
       └── 每次对话时发给 Ollama 模型
            │
            └── 每 50 条消息自动重发一次（防失忆）
```

## 常见问题

**Q: 修改规则后小智的行为没有变化？**
A: 请确认保存后**重启了程序**。规则只在启动时加载一次。

**Q: 规则写错了导致小智出问题？**
A: 删除 `config/ai_rules.txt` 文件，重新启动程序会自动生成默认规则。

**Q: 可以加表情符号吗？**
A: 可以，规则是纯文本，任何文字都支持。
